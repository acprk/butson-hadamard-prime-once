1. (a) 尝试推翻定理 S：构造对照与独立穷举
======================================================================

1.1 已知构造逐一对照（均与定理 S 相容）
- Chu / Frank–Zadoff：长度 n 取值于 µ_n（n 奇）或 µ_{2n}（n 偶）。若 p ∥ n，则 p | h；n 偶时 4 | 2n。不冲突。
- Frank：n = m^2，任何 p | n 都有 ν_p(n) ≥ 2。不适用。
- Milewski：n = m^{2k+1}，h = m^{k+1}。p ∥ n 迫使 k = 0，此时 h = m，有 p | h。不冲突。
- Duc–Schmidt 的 BH(Z_{p^a},h)：p ∥ p^a 只在 a = 1 时成立，此时需要 p | h（[DDS19, Thm 3.5]），与 S 的 H = 1 情形一致。
- Menon / PQA：BH(G,2) 要求 |G| = 4u^2。奇素数 p ∥ 4u^2 不可能；p = 2 时 h = 2 ≡ 2 (mod 4)，而 |G| ≡ 0 (mod 4)。不适用。
- Kronecker（张量）积 BH(G1,h1)⊗BH(G2,h2)：p ∥ |G1×G2| 意味着 p 只整除其中一个因子且恰为一次，归纳上相容。
- 非循环构造：Do Duc [DD19b, Thm 4.3] 的 BH(R×R,h)，|G| = |R|^2，ν_p ≥ 2，不适用（稿中也把它当作 ν_p = 2 时的锐性例子）。[LYZ26] 的 type [m,q]（m ≥ 3 奇）中 2^m ∥ |G|，m ≥ 3，不适用。Davis–Jedwab–Mowbray 的 (12,3,12,4)-RDS 给出 BH(C_2^2×C_3,3)：3 ∥ 12 但 3 | h，不适用。

1.2 本审稿人独立编写的搜索（C + OpenMP，nice 10，≤ 8 线程；另有 numpy MITM）

2. (b) 寻找证明中的隐藏漏洞
======================================================================

我逐条检查了任务点名的五个可疑点，结论是证明成立。说明如下，也供作者在修改稿中把相应论证写得更显式。

2.1 素理想 ℘ 在不同特征 χ 之间的选取。
引理 4.2 对每个 χ 给出 q_χ ∈ {℘, ℘̄}，可能随 χ 变化。但 (2) 用的是 c·c̄ ∈ ℘：若 c ∈ ℘̄，则 c̄ ∈ ℘，乘积仍在 ℘ 中。所以对固定的 ℘ 无条件成立。Parseval 和式中每项 |χ(c_k)|^2 = χ(c_k)·conj(χ(c_k)) 都在同一个 ℘ 中，这里需要 O = Z[ζ_L] 在复共轭下封闭（成立）。没有问题。

2.2 单个陪集上的 Parseval。
Σ_{χ∈H^} |χ(c_k)|^2 = |H|·Σ_x |c_k(x)|^2 = |H|^2 是 H 上的标准 Plancherel，只用到 c_k 的系数是单位根。左边属于 ℘ ∩ Z = pZ，而 p ∤ |H|。没有问题。Remark 4.3 关于“不能对 k 求和”的说明正确，也有启发性。

2.3 p ∉ ℘^2 的使用。
需要 v_℘(n) = 1。这里 n = |G| ∈ Z，v_p(n) = 1，且 p 在 Z[ζ_L] 中不分歧（L = lcm(h′, exp H)，p ∤ L），所以 v_℘(n) = e·v_p(n) = 1。没有问题。附带一点：若 ℘ = ℘̄，则 z ∈ ℘ ⟺ z̄ ∈ ℘，直接矛盾。这正是 Turyn 自共轭情形，稿中已说明。

2.4 h ≡ 2 (mod 4) 的约化 µ_h = ±µ_{h/2}。
h′ = h/2 为奇数，−ζ_{h′}^k 恰好遍历 µ_{2h′} \ µ_{h′}，所以 µ_h = ±µ_{h′} ⊂ Z[ζ_{h′}]。又 2 ∥ |G| ⇒ |H| 奇 ⇒ L 奇 ⇒ 2 在 O 中不分歧。证明中系数的模长仍为 1。没有问题。

2.5 “局部环”步骤是否要求剩余域特征为 p。
需要，而且满足：℘ | p，所以 O/℘ 的特征是 p，从而 T^p − 1 = (T − 1)^p。若取的素理想不在 p 上方则不成立，但证明没有这样做。还有一个细节：F^* = Σ c̄_k T^{−k} 的约化为 0，等价于所有 c̄_k ∈ ℘。这一点正确。

2.6 其他检查（无误，但建议写明）
- G = H × C_p 的直积分解：p ∥ |G| ⇒ Sylow p-子群为 C_p 且是直因子。正确。
- 部分求值是与 * 交换的环同态，因为 χ(s^{−1}) = conj χ(s)，且 χ 的值在 O 中。正确。
- Lean 陈述（我本机执行 #print axioms）：
  no_perfect_function_sharp : ∀ G [AddCommGroup G] [Fintype G] (h p), p.Prime → p ∣ |G| → ¬p^2 ∣ |G| → (¬p∣h ∨ p=2 ∧ ¬4∣h) → ∀ a : G → ℂ, (∀ g, a g ^ h = 1) → (∀ s ≠ 0, Σ_g a(g+s)·conj(a g) = 0) → False
  公理为 [propext, Classical.choice, Quot.sound]；no_perfect_function 同样。h = 0 的退化情形已被 (¬p∣h ∨ …) 排除（p ∣ 0 且 4 ∣ 0）。陈述忠实于定理 4.1。
  RDS 推论、Lemma A、Theorem C 的 Lean 文件我没有复核。
- 推论 R 的证明我手工复核：φ = ψ^{p^v} 的阶整除 |G|/p^v；φ(x) ≠ 1 因为 ord x 与 p 互素；差分计数 λ·n = m。正确。
- 引理 5.7（下降界取等）我手工复核：取等 ⇒ d_i ∈ {0,C}，且所有非互素 t 处 D′(ζ_F^t) = 0 ⇒ E 在 C_F/C_r 上的像为 (r/2)J，不是整数。正确。c_t ≤ 4N/L 的推导（|µ_4 ∩ µ_d| = 4d/L）也正确。

结论：没有找到数学漏洞。但审稿人需要指出，证明的正确性恰恰加重了新颖性问题：一个三步、不用任何深刻工具的证明，覆盖了 Ma (1996)、Ma–Ng (2009)、LSZ (2023)、Lv (2017)、Ying–Deng (2026) 等用 Weil 数、类群、域下降逐族证明的结果。编辑和专家审稿人第一反应必然是“这是不是民间已知的”。作者现有的证据（“三条事实表明专家不知道”）属于间接推断，不是文献核查。
