2. 新 Corollary 1.2 的核验
======================================================================
论文陈述：n 为 square-free 时，BH(Z_n,h) 存在 ⇔ n | h 且（n 为偶数 ⇒ 4 | h）。

(1) Do Duc Result 4.1 原文（1903.07334v2 第 21 页）：
    "Let n and h be positive integers. Then a BH(Z_n, h) matrix exists whenever n and h
     satisfy the following condition: n | (h, n)² and (ν_2(n), ν_2(h)) ≠ (1, 1)."
    其中注明这是 "a direct corollary of Result 1.5"，即 Duc–Schmidt [10]
    Cor 2.5；同文 Introduction 第 2 页也直接写了 (i)(ii) ⇒ 存在。
    n 为 square-free 且 n | h 时，(h,n)=n，n | n² 成立。
    - n 为奇数：ν_2(n)=0，第二个条件自动成立。
    - n 为偶数：ν_2(n)=1，需要 ν_2(h)≠1；又因 2 | n | h，所以等价于 4 | h。
    因此 Result 4.1 对所有 square-free 的 n 都给出充分性。
    反过来，square-free 的 n 满足 n | (h,n)² 当且仅当 n | h，所以必要性方向的条件与
    S′ 给出的条件恰好重合：p | h 对所有 p | n；n≡2 (mod 4)，也就是 n 为偶数时 4 | h。
    逻辑闭合。

(2) 边界情形
    - n=1：任何 h ≥ 1 都存在（1×1 矩阵），与 "1 | h" 一致。
      注意 Mow 猜想原文要求 n>1，Corollary 1.2 包含 n=1 不会引起矛盾。
    - n=2：充要条件是 4 | h。h=2 时不存在，h=4 时存在（(1,i)），与 DS19 Thm 3.6 一致。
    - h=n 与 h=2n：n 为奇数时 h=n 已经足够。n 为偶数（n≡2 mod 4）时，h=n 不够
      （ν_2=1），h=2n 足够（ν_2=2，且 n | 2n）。这与 "a circulant BH(2p,h) 存在 ⇔
      4p | h" 一致（lcm(2p,4)=4p）。
    - 唯一的隐含前提是 h ≥ 1，建议在陈述中写明 "positive integers"。

(3) 穷举验证（我自己写的程序，/tmp/bhchk/bf.py，固定 a_0=1）
    n ∈ {1,2,3,5,6,7}：对 μ_h^{n-1} 全枚举，检查所有 |DFT|² = n。
    n = 10：用 C_5×C_2 中途相遇（按 |χ(c_0)|²+|χ(c_1)|²=10 建哈希，再检查
    Re(χ(c_0)·conj χ(c_1))=0），并在 n=6 上与全枚举交叉验证，结果一致。
    h = 1..12，共 84 个 (n,h) 格子，与 Corollary 1.2 的断言全部一致（0 个不符）。
    存在的格子恰好是：
      n=1 时所有 h；n=2: h=4,8,12；n=3: h=3,6,9,12；n=5: h=5,10；n=6: h=12；
      n=7: h=7；n=10: h≤12 时一个也没有。
    补充检查：n=10, h=20 存在，n=10, h ∈ {4,10} 不存在；n=6, h ∈ {4,6} 不存在。
    两个方向都与断言相符。

(4) "Mow 和 Do Duc 的猜想对 square-free 的 n 成立" 这一说法：准确。
    Mow 猜想（K.-U. Schmidt 综述 Conj 4.1.1）在 n square-free 时 r=n、√(rn)=n。
    n≡2 (mod 4) 时 2n | H ⇔ n | H 且 4 | H，与 Corollary 1.2 完全相同。
    "if" 方向是 Mow 证明的，综述 Theorem 4.1.7 也给出了构造。
    要提醒的是，"首次证明" 的先行性取决于 LCZ25（n=2p、n=6）和 MaNg09（2p^s，只针对
    p-ary），这一点尚未落实。素数幂情形早已由 DS19 Thm 3.6 完全解决。建议在
    Corollary 1.2 后写明：n 为素数（幂）的情形是 DS19 Thm 3.6；n=2p 的情形需与 LCZ25
    对照。
    充分性方向建议同时直接引用原始出处 DucSchmidt2019 Cor 2.5（以及
    Schmidt2016survey Thm 4.1.7），不要只引用二手的 Result 4.1。

4. Corollary R ⊇ LSZ23 §6 的核对（LSZ2023_RDS_060822_final.pdf 第 18–22 页）
======================================================================
LSZ23 中 (pn, n, pn, p) RDS 的 |G/N| = pn，|N| = n。当 p∤n 且 n ≥ 2 时 p ∥ |G/N|，
而 N 不是 p-群，所以由 Corollary R 可知不存在。逐条核对如下。
- Thm 6.1：(pq^r, q^r, pq^r, p)，p 和 q 是不同的素数，n=q^r ≥ 2 与 p 互素。Corollary R
  无需条件 (a)–(c) 即可推出。✓
- Thm 6.2：其假设 n>1 且与 p 互素，本身就已经推出不存在，结论中的 p 的上界因此变得
  多余。✓
- Cor 6.3（对固定的 n，只有有限个 p）：由 Corollary R 立即得到，因为能出现的 p 只能是
  n 的素因子。论文说的 "stronger form" ✓
- Cor 6.4：在 gcd(p,n)=1、n ≥ 2 的范围内 ✓。论文脚注指出字面上允许 n=1，我核对过：
  (p,1,p,p) RDS 取 D=G=C_p 时确实存在，所以字面陈述在 n=1 时为假，原证明经由
  Thm 6.2 要求 n>1。脚注措辞准确且中立。✓
- Thm 6.5：(pq, q, pq, p)，n=q ✓，也不需要 "p,q 为奇数" 和 gcd(p,q−1)=1 这两个条件。✓
另外两点：
- 论文说 Corollary R 是 Thm 5.1(a) 在 b=1 时去掉 self-conjugacy 条件的情形，核对正确：
  q | n，p ≠ q，p ∥ mn。
- 表中 "?" 条目已全部核对。Table 1 的 ? 是 n=24、96、98；Table 2 是 12、13、39、48；
  Table 3 是 12、20、48、49、80、98。论文判定的 8 个和 "其余 5 个没有恰好整除一次的素数"
